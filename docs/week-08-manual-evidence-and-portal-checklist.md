# Exact manual evidence and portal-recovery checklist

> **Status as of 2026-08-24:** Public source artifacts exist for much of the program, but the official FlyRank submissions page lists **only BE-01**. A saved form is not the same as a persisted or accepted submission. This checklist separates public artifacts from evidence that only the participant can honestly create. [1]

## Use this order for every portal retry

Open the listed assignment URL while authenticated. Paste only the public link(s) shown below, add the factual note, click **Save submission**, then immediately open `/intern/submissions`. Record the timestamp and the visible result. If the entry is absent, do not claim it was submitted; keep the screenshot or written observation and contact FlyRank Support with the assignment ID, the public links, and the persistence result. This procedure cannot resolve the recurring portal defect by itself.

| Status label | Meaning |
| --- | --- |
| **Public source built** | A reproducible repository, portfolio document, or local evidence record exists. |
| **Form save attempted** | A previous portal form save was clicked, but it is not official unless it appears in `/intern/submissions`. |
| **Participant-only** | Requires a real personal account action, observation, recording, explanation, post, profile update, or independent review. It cannot be replaced by drafted copy. |

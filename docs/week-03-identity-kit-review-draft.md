## Proposed visual system

| Role | Proposed choice | Value | Rationale |
| --- | --- | --- | --- |
| Heading type | DM Serif Display | Google Fonts family | Gives major headings editorial weight without requiring decorative illustration. |
| Body and UI type | IBM Plex Sans | Google Fonts family | Keeps technical explanations and interface controls readable. |
| Main ink | Charcoal | `#1E2521` | A softer near-black for dense technical text. |
| Background | Paper | `#F6F1E8` | A warm near-white for long-form case-study reading. |
| Accent | Signal red | `#D9472F` | Reserved for meaningful actions and status signals. |
| Supporting surface | Sage | `#D8E5D4` | A restrained note or success-state surface. |

The proposed style rule is: use the display face for major headings and the sans-serif face for body copy, code-adjacent labels, and controls; use charcoal on paper, with signal red only where a meaningful action or state needs emphasis. The intended mood is **calm, editorial, and evidence-led**—the work should remain visually louder than the brand treatment.

## Usage guardrails

Use no more than these four colors on one page. Keep the accent out of page backgrounds, leave clear space around a mark, and avoid competing gradients, large illustrations, or additional display fonts. These rules are design suggestions, not a claim about an already adopted public brand.
